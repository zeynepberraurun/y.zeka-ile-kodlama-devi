About Me

Engineering Reliable Foundations Behind the Scenes

I am a 2nd-year Computer Programming student at Anadolu University specializing in Backend Software Development. My work centers on designing and implementing clean server-side systems where performance, maintainability, and data integrity come first.

Whether structuring domain models with C# and ASP.NET Core MVC, building lightweight microservices with Python & Flask or Node.js, or optimizing complex queries across SQL Server and MySQL, I approach every problem with an analytical, systems-first mindset.

Beyond application code, I embrace modern DevOps practices—packaging services into reproducible Docker containers, orchestrating workloads with Kubernetes, and automating delivery through CI/CD pipelines on Linux/WSL and AWS.
